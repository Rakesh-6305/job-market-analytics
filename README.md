# Final Project

This repository contains a Flask dashboard and model code.

Quick start:

1. Create a Python virtual environment and install dependencies:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Run the app:

```bash
python app/app.py
```

Notes:
- Update your `git` user name/email before pushing: `git config user.name "Your Name"` and `git config user.email "you@example.com"`.
- To publish to GitHub, provide a repo name and whether you want it public or private.
